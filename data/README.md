# Dados

Os CSVs **não** são versionados (são grandes). Para reproduzir:

1. Acesse https://www.kaggle.com/datasets/shuyangli94/food-com-recipes-and-user-interactions
2. Baixe o dataset (botão *Download*) e extraia o zip.
3. Copie para esta pasta **apenas** estes dois arquivos:
   - `RAW_interactions.csv`
   - `RAW_recipes.csv`

Os demais arquivos (`PP_*`, `interactions_train/test/validation`) não são usados.
